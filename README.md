# MyFirstApp

This repository now contains a basic .NET MAUI starter app for Windows desktop, Android, and iOS.

## What it does

- lets the user choose the time their day job ends
- starts a countdown to that time
- shows a completion message when the countdown reaches zero
- remembers the last chosen finish time with local persistence

## Why this starter is useful for teaching

The project is intentionally small and beginner-friendly. It already includes practical examples of:

- variables and properties
- if/else logic
- classes and object-oriented design
- inheritance through a small observable base class
- loops and collections
- local data persistence
